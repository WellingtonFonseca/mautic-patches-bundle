# Patches: list status, toggles, plugin tiles, notifications

The active / inactive status of the segment, campaign, user and email lists (Ativar / Desativar first in the row menu; the Status column and the `.patches-badge` are in wiki/patches-status-column.md), the loader of the list toggles, the plugin tiles of Settings > Plugins, the fixed notifications, the delete hover and the live mode icon.
